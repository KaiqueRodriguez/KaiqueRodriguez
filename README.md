Desde então, venho aprofundando meus conhecimentos por meio de estudos e projetos práticos, com foco principalmente em Front-End e Python. Busco constantemente aprimorar minhas habilidades, aprender novas tecnologias e desenvolver soluções que contribuam para meu crescimento profissional.
